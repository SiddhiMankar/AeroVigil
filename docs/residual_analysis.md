# AeroVigil DT — Residual Analysis, Anomaly Detection & Fault Classification Specification

## 1. Overview & Purpose

In **AeroVigil DT**, **Phase 3 (Residual Analysis & Anomaly Detection)** transforms the raw residuals generated by the Digital Twin into explainable diagnostic outputs:

$$\text{Telemetry} \longrightarrow \text{Digital Twin} \longrightarrow \text{Normalized Residuals } (\mathbf{z}) \longrightarrow \text{ResidualAnalyzer} \longrightarrow \begin{cases} \text{Global Anomaly Score } (0\text{--}100) \\ \text{Anomaly Level } (\text{NORMAL, WARNING, ANOMALOUS, CRITICAL}) \\ \text{Rule-Based Fault Class} \\ \text{Severity Level } (\text{NORMAL, LOW, MEDIUM, HIGH, CRITICAL}) \\ \text{Evidence / Confidence Score } (0.0\text{--}1.0) \\ \text{Contributing Signals \& Reasoning} \end{cases}$$

> **CORE PRINCIPLE**: The diagnostic classifier does **NOT** operate directly on raw telemetry values, nor does it inspect ground-truth scenario labels. It operates strictly on **physics-informed normalized residuals** ($\mathbf{z}$), residual persistence, and multi-sensor correlation patterns.

---

## 2. Normalized Residual Calculation & Thresholds

For each modeled signal $i \in \{\text{RPM, CHT, EGT, oil\_pressure, oil\_temperature, fuel\_flow, vibration, battery\_voltage}\}$:

$$z_i(t) = \frac{\text{Observed}_i(t) - \text{Expected}_i(t)}{\sigma_{i, \text{nominal}}}$$

### Prototype Anomaly Thresholds
* $|z_i| < 2.0\sigma$: **Nominal** (within expected operating noise)
* $2.0\sigma \le |z_i| < 3.0\sigma$: **Warning / Low Deviation**
* $|z_i| \ge 3.0\sigma$: **Anomalous / Significant Deviation**
* $|z_i| \ge 4.5\sigma$: **Critical / Severe Deviation**

---

## 3. Temporal Persistence Engine

To prevent single-sample noise spikes from triggering false alarms, temporal persistence requires $N$ consecutive samples (default $N = 3$ seconds at 1 Hz) above the anomaly threshold:

$$\text{persistent\_anomaly}_i(t) = \prod_{k=0}^{N-1} \mathbb{I}\left(|z_i(t-k)| \ge 3.0\sigma\right)$$

---

## 4. Global Anomaly Score & Level

The global anomaly score $S \in [0.0, 100.0]$ is computed as a weighted aggregation of significant normalized residuals ($|z_i| \ge 2.0\sigma$):

$$S_{\text{raw}} = \frac{\sum_{i} w_i \cdot \max\left(0, |z_i| - 1.5\right)^{1.3}}{\sum_i w_i} \cdot 22.0$$

$$S_{\text{score}} = \min\left(100.0, \max\left(0.0, S_{\text{raw}}\right)\right)$$

### Anomaly Level Mapping
* $S_{\text{score}} < 15.0$: **`NORMAL`**
* $15.0 \le S_{\text{score}} < 35.0$: **`WARNING`**
* $35.0 \le S_{\text{score}} < 65.0$: **`ANOMALOUS`**
* $S_{\text{score}} \ge 65.0$: **`CRITICAL`**

---

## 5. Interpretable Rule-Based Fault Signatures

| Fault Classification | Residual Signature Pattern | Diagnostic Interpretation |
|---|---|---|
| **`NORMAL`** | All $|z_i| < 2.0\sigma$ | Healthy baseline engine operation |
| **`OVERHEATING`** | $z_{\text{CHT}} \ge 2.5\sigma$ **AND** $z_{\text{EGT}} \ge 2.5\sigma$ | Multi-signal thermal breakdown (cooling failure / lean mixture) |
| **`LUBRICATION_FAULT`** | $z_{\text{oil\_pressure}} \le -2.5\sigma$ **AND** $z_{\text{oil\_temperature}} \ge 1.5\sigma$ | Hydraulic pressure loss & friction heat (oil pump / leak) |
| **`VIBRATION_ANOMALY`** | $z_{\text{vibration}} \ge 2.5\sigma$ | Mechanical unbalance, bearing degradation, or misfire |
| **`SENSOR_DRIFT`** | Exactly ONE primary sensor $|z_{s_1}| \ge 3.0\sigma$, while correlated physical sensors $|z_{s_{\text{other}}}| < 2.0\sigma$ | Isolated electrical sensor bias (e.g. CHT probe failure) |
| **`UNKNOWN_ANOMALY`** | $|z_i| \ge 3.0\sigma$ or $S_{\text{score}} \ge 30.0$, but unmatched by known rules | Unidentified anomaly requiring inspection |

---

## 6. Sensor-Drift Discrimination Logic

Physical engine failures inherently cause multi-signal thermodynamic changes (e.g., actual cylinder overheating causes both CHT and EGT to spike, and eventually oil temperature).

In contrast, an electrical sensor drift affects only the targeted sensor probe:

$$\text{If } z_{\text{CHT}} = +14.2\sigma \text{ BUT } z_{\text{EGT}} = -0.04\sigma \text{ AND } z_{\text{oil\_temperature}} = +0.24\sigma \longrightarrow \mathbf{\text{SENSOR\_DRIFT}}$$

This pattern allows **AeroVigil DT** to prevent false emergency engine shutdowns caused by faulty sensors.

---

## 7. Transparent Evidence / Confidence Score

The evidence score $E \in [0.0, 1.0]$ represents diagnostic signature fit quality:

$$E = \min\left(0.98, \text{Base\_Score} + \Delta E_{\text{magnitude}}\right) \cdot \text{Persistence\_Factor}$$

* Documented as a heuristic evidence score based on signature match quality and persistence.
* **Not** a deep learning black-box probability claim.

---

## 8. Diagnostic Severity Categories

* **`NORMAL`**: No persistent anomalies ($S_{\text{score}} < 15$).
* **`LOW`**: Warning threshold breached ($2.0\sigma \le |z_{\max}| < 3.0\sigma$).
* **`MEDIUM`**: Single anomaly or sensor drift ($3.0\sigma \le |z_{\max}| < 4.5\sigma$).
* **`HIGH`**: Severe anomaly or persistent thermal/hydraulic fault ($4.5\sigma \le |z_{\max}| < 6.0\sigma$).
* **`CRITICAL`**: Multi-signal persistent critical fault ($|z_{\max}| \ge 6.0\sigma$, $S_{\text{score}} \ge 65$).

## 10. Limitations & Disclaimers

1. **Prototype Thresholds**: Thresholds ($\pm 2.0\sigma, \pm 3.0\sigma, \pm 4.5\sigma$) are prototype values tailored for SIH 2026 technical demonstration.
2. **Explainable Rules**: Rules are deterministic and interpretable; complex unmodeled multi-fault interactions trigger `UNKNOWN_ANOMALY` for safety.
