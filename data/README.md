# AeroVigil DT — Telemetry Datasets Directory

This directory contains synthetic telemetry CSV files generated by `scripts/generate_datasets.py` for testing and downstream pipeline evaluation.

> **DISCLAIMER**: All telemetry datasets in this directory are **synthetic prototype datasets** generated by `src/simulator.py`. They do **not** represent certified physical aircraft measurements or specific proprietary UAV engine specifications.

---

## Telemetry Schema & Units

Each CSV file contains 13 columns:

1. `timestamp` — UTC ISO-8601 string (1 Hz sampling)
2. `timestamp_sec` — Elapsed flight seconds (`0.0` to `1199.0`)
3. `mission_phase` — Flight phase (`STARTUP`, `TAKEOFF`, `CLIMB`, `CRUISE`, `MANEUVER`, `DESCENT`, `LANDING`)
4. `throttle` — Throttle command ratio (`0.05` – `1.0`)
5. `ambient_temperature` — Outside air temperature (°C)
6. `RPM` — Engine rotational speed (rev/min)
7. `CHT` — Cylinder Head Temperature (°C)
8. `EGT` — Exhaust Gas Temperature (°C)
9. `oil_pressure` — Lubrication system pressure (psi)
10. `oil_temperature` — Lubrication oil temperature (°C)
11. `fuel_flow` — Fuel flow rate (L/h)
12. `vibration` — Normalized engine block vibration (g)
13. `battery_voltage` — Electrical system voltage (V)
